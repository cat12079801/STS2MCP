# 親指締め具の入力の契約試験

`dotnet run --project tests/ThumbscrewStateContract -c Release`

- 本番の星 X reader をリンクする。5 つの戦闘パイル、同名別個体、保存値と星残高、0、Chemical X 相当の hook、エナジー不足を星で払う分岐、自動プレイで保存・保持した値、getter の個別欠測を検査する。再取得が保存値・残高・パイル・履歴を書き換えないことも検査する。
- 本番の矢 reader と敵 ID の採番をリンクする。枠なし・枯渇・末尾優先・刺突順・回収・破壊・所有者と対象の照合、コードや参照を読めない場合、枠と件数の矛盾を検査する。
- JSON の型と欠測、通常戦闘・選択画面へ付ける共通 builder の配線、戦闘外・候補・強化プレビューへの適用範囲を検査する。ゲームの境界を stub に差し替えて動かす。
